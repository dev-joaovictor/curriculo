# Currículo — João Victor

Site com projetos e perfil profissional.

**Ao vivo:** https://ben10informatica.github.io/curriculo/

Stack: React · TypeScript · Vite

## Rodar local

```bash
npm install
npm run dev
```

Acesse `http://localhost:5173`.

## Dados

Edite `src/data/projects.ts` para nome, bio, links e lista de projetos.

## Build

```bash
npm run build
```

Deploy automático via GitHub Pages a cada push na `main`.
